# Solitaire Çeşitleri

Yedi temel solitaire (Klondike, Serbest Hücre, Yukon, Akrep, Örümcek, Kırk Haramiler, Canfield) üzerine bir ya da iki kural değiştirici uygulanarak elde edilen 100 çeşit. Her çeşit 10.000 bölüm (toplam 1.000.000); her dağıtım çözücüyle denetlenir. 33 dil. Kart Oyunları merkez uygulamasında tek kutucuk altında listelenir; ortak motor: kart-motoru.
